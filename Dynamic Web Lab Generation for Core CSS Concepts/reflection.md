# Reflection (draft, edit in your own words before submitting)

Using the AI to make these labs helped me more than I thought it would. I already knew the words padding, margin and border, but moving a slider and watching the green and orange areas grow made it click properly. The thing I learnt that I didn't expect was margin collapsing. In the first version the orange margin colour wasn't showing above and below the boxes, and when I asked why, it explained that the box's top and bottom margins were collapsing through the wrapper. I would not have picked that up from just reading notes. The Flexbox/Grid playground was the same. Switching justify-content between space-between, space-around and space-evenly one after another showed me the difference faster than any diagram.

Doing it step by step worked better for me than trying to get everything in one big prompt. My first prompt gave me a working box model lab, but once I used it I saw what was missing, like separate sliders for each side, and could ask for exactly that. If I had written one huge prompt at the start I wouldn't have known what to ask for, and if something broke it would be harder to tell which part caused it. The downside is that it takes more time and I had to actually test each version in the browser. But that testing is where most of the learning happened.

The main thing I'd watch out for is not just copying what the AI gives back. A couple of times the code looked fine but didn't do exactly what I wanted, and I only noticed because I was clicking through it myself. So I'd say AI is good for building the tool you learn with, but you still have to use it and question it yourself.
