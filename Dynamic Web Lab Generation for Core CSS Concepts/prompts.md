# Prompts used

## 1. Box Model lab (initial)

> Create a single HTML file (HTML, CSS and JavaScript all in one) that works as an interactive CSS box model lab. Show two boxes labelled "Box 1" and "Box 2". Give the content, padding and margin areas different background colours so I can tell them apart, and give each box a solid border. Add sliders with value labels for padding, margin, border-width and width that update both boxes live. Add a dropdown to switch display between block, inline-block and inline.

## 2. Box Model lab (refinement)

> Update the box model lab. Replace the single margin, padding and border sliders with separate sliders for top, right, bottom and left for each one. Add a border-radius slider. Keep the value labels next to every slider. Also show the current CSS being applied to the boxes so I can see what changes.

## 3. Flexbox / Grid playground

> Create a single HTML file that is a Flexbox and Grid playground. Make a container with 5 items in it. Add dropdowns for display (flex / grid), flex-direction, justify-content, align-items and grid-template-columns. When I change any dropdown the container should update in real time.
